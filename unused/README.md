# Unused resources

Kept on purpose; nothing on the live site loads these files.

- `fluent-emoji/`: the first Fēlix (Fluent Emoji cat faces) and the first icon set (fire, star, crown, sun, moon, temple and others). Microsoft Fluent Emoji, MIT License (see `LICENSE-fluent-emoji.txt`).
- `felix-bust/`: the second Fēlix, an upper-body toga cat holding a tablet, one pose for every mood. Replaced by the current bust in `img/felix/`, which has livelier faces and a pose per mood (drawn by `tools/felix.py`).
- `bayleaf-theme-toggle.html`: the Bay Leaf day/night toggle exactly as provided, as a standalone working page. Verba uses an adapted copy (Verba colors, `verba-theme` storage key).
